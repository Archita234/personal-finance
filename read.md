# Personal Finance Health Score & Anomaly Detection

## Project Overview
This project analyzes customer financial transactions to evaluate financial health, detect anomalous transactions, and segment customers using machine learning techniques.

## Objectives
- Analyze customer spending patterns.
- Calculate a Financial Health Score.
- Detect anomalous transactions.
- Classify customers based on financial health.
- Segment customers using K-Means clustering.

## Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Financial Health Score Calculation
- Rule-Based Anomaly Detection
- Decision Tree Classification
- Random Forest Classification
- K-Means Clustering
- Interactive Dashboard using Streamlit

## Dataset
The project uses a bank transaction dataset along with generated customer, budget, and income data.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
